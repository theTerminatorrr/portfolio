# Heart Disease Predictor (static site)
Deploy these files: index.html, style.css (or style-red.css), script.js, model.js
Theme: in index.html switch href="style.css" <-> href="style-red.css".
GitHub link: edit YOUR-USERNAME/YOUR-REPO in index.html.
Retrain: python export_model.py (regenerates model.js).
Deploy: GitHub Pages (Settings > Pages > main branch) or Vercel (import repo, framework "Other"). No build step.
Also works by double-clicking index.html (no fetch is used).
